# JDKMan（jdm）架构设计说明

> 对应提示词《jdk管理工具-开发提示词.md》输出要求第 1 条。确认后作为编码基线。

## 1. 总体架构

单一 Cargo workspace，三 crate；GUI 与 CLI 均为薄壳，全部业务逻辑收敛在 `jdm-core`（纯 Rust、零 Tauri 依赖、可单测）。

```
┌──────────────── jdm-tauri（GUI 壳）────────────────┐
│ Vue 3 + TS + Vite + Element Plus（i18n / 明暗主题）  │
│  pages: Available / Installed / Projects / Settings │
└────────△───────────────────────△───────────────────┘
         │ invoke / event（下载进度）│
┌────────┴─────────┐      ┌─────────┴────────┐
│  jdm-tauri cmds  │      │  jdm-cli (clap)  │
└────────┬─────────┘      └─────────┬────────┘
         └────────────┬─────────────┘
              ┌───────┴────────────────────────────────┐
              │               jdm-core                 │
              │  source │ downloader │ installer       │
              │  switcher │ project │ shim │ store    │
              └────────────────────────────────────────┘
```

## 2. jdm-core 模块职责

全异步（tokio）；所有路径经 `JdmHome` 注入（不直接读 `$HOME`），便于单测用临时目录。

| 模块 | 职责与关键设计 |
|---|---|
| `source` | trait `VersionSource`：`FoojaySource`（默认）、`AdoptiumSource`（Temurin 加速）、`CustomSource`（自定义镜像，兼容 foojay 路径规则）。统一输出 `Release { vendor, version, feature, lts, packages[] }`，package 含 os/arch/包类型/直链/sha256/size |
| `downloader` | reqwest + tokio；先 HEAD 探测 Range 支持：支持则 4–8 分块并发 + 断点续传（`.part` + `.part.json` 状态文件），否则降级单流；SHA-256 边下边算。校验和来源优先级：API 字段 → `<url>.sha256.txt` → 均无则**拒绝安装** |
| `installer` | zip（Win）/ tar.gz（Unix）解压 → 探测归档内一层根目录（如 `jdk-17.0.12+7`）→ 移入 `versions/<vendor>_<ver 消毒>` → 运行 `bin/java -version` 验证 → 写入 `index.json`；"导入本地 JDK"复用同一安装流程（跳过下载与校验） |
| `switcher` | 写 `default` → 重建 `current` 链接（**Unix 用 symlink；Windows 用目录 junction，免管理员权限**）→ 重建 shim → Windows 写 HKCU\Environment：JAVA_HOME 指向 `%USERPROFILE%\.jdm\current`，用户 PATH 确保含 `~/.jdm/bin`（只加一次），`SendNotifyMessage(HWND_BROADCAST, WM_SETTINGCHANGE)` 广播。先备份后写入，失败回滚 |
| `project` | `projects.json` 读写；`.jdmrc` 为单行 `<vendor>@<version>`；`resolve(cwd)` 从 cwd 向上逐级查找 |
| `shim` | 单二进制 `jdm-shim` 按 **argv[0] 文件名分发**（busybox 式），覆盖 java / javac / jar / jshell / jlink / jpackage / javaw 共 7 个高频命令，安装/切换时复制为各命令名放入 `~/.jdm/bin` |
| `store` | `index.json` / `projects.json` / `setting.json` / `default` 的读写与校验；`tracing` 日志滚动写入 `logs/` |

## 3. 关键决策（对应提示词"与 Node 的关键差异"）

1. **shim 只做 7 个高频命令**；其余工具靠 `JAVA_HOME` 覆盖（mvn/gradle 自读）。shim 解析出 JDK 后**额外为子进程注入 JAVA_HOME**，保证项目级 mvn/gradle 也不依赖全局变量。
2. **版本唯一键 `vendor@version`**（如 `temurin@17.0.12+7`）；目录名消毒 `+` → `_`（`temurin_17.0.12_7`）。
3. **解析优先级统一**（shim 与 CLI 同一套 `resolver`）：cwd 向上找 `.jdmrc` → `projects.json` 命中最近的项目根祖先 → 全局 `default`。
4. **Windows 文件占用**：卸载/切换前预检 `versions/<dir>` 可重命名性，被占用时给出"关闭相关进程"提示而非半途失败。
5. foojay disco API 若要求鉴权，设置中提供可选 API Key 字段；Adoptium 免 Key 作为备选默认。

## 4. 磁盘布局

```
~/.jdm/
├── versions/temurin_17.0.12_7/   # 每个 JDK 一个独立目录（归档解压内容）
├── bin/                          # jdm-shim 的副本：java.exe、javac.exe…
├── current                       # → versions/temurin_17.0.12_7（symlink / junction）
├── default                       # 单行：temurin@17.0.12+7
├── index.json                    # 本地已装版本索引
├── projects.json                 # 项目 → 版本绑定
├── setting.json                  # 数据源 / 代理 / 语言 / 主题
└── logs/jdm.log.YYYY-MM-DD       # 滚动日志
```

## 5. 核心数据结构（JSON Schema 草案）

### 5.1 `~/.jdm/setting.json`

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "setting.json",
  "type": "object",
  "required": ["source", "language", "theme"],
  "properties": {
    "source": { "enum": ["foojay", "adoptium", "custom"], "default": "foojay" },
    "customSourceUrl": { "type": "string", "default": "", "description": "source=custom 时的镜像根 URL（兼容 foojay 路径规则）" },
    "sourceApiKey": { "type": "string", "default": "", "description": "foojay disco API Key（如该部署要求）" },
    "proxy": {
      "type": "object",
      "properties": {
        "enabled": { "type": "boolean", "default": false },
        "url": { "type": "string", "examples": ["http://127.0.0.1:7890"] }
      }
    },
    "language": { "enum": ["zh-CN", "en-US"], "default": "zh-CN" },
    "theme": { "enum": ["light", "dark", "system"], "default": "system" }
  }
}
```

### 5.2 `~/.jdm/projects.json`

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "projects.json",
  "type": "object",
  "required": ["version", "projects"],
  "properties": {
    "version": { "const": 1 },
    "projects": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["path", "jdk"],
        "properties": {
          "path": { "type": "string", "description": "项目根绝对路径，统一 / 分隔" },
          "name": { "type": "string" },
          "jdk": { "type": "string", "pattern": "^[a-z0-9-]+@.+$", "examples": ["temurin@17.0.12+7"] },
          "addedAt": { "type": "string", "format": "date-time" },
          "lastUsedAt": { "type": "string", "format": "date-time" }
        }
      }
    }
  }
}
```

### 5.3 `~/.jdm/index.json`（本地已装版本索引）

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "index.json",
  "type": "object",
  "required": ["version", "installed"],
  "properties": {
    "version": { "const": 1 },
    "installed": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["id", "vendor", "version", "dir", "installedAt"],
        "properties": {
          "id": { "type": "string", "pattern": "^[a-z0-9-]+@.+$" },
          "vendor": { "type": "string", "examples": ["temurin"] },
          "version": { "type": "string", "examples": ["17.0.12+7"] },
          "feature": { "type": "integer", "examples": [17] },
          "lts": { "type": "boolean" },
          "dir": { "type": "string", "examples": ["temurin_17.0.12_7"], "description": "versions/ 下目录名" },
          "javaVersionOutput": { "type": "string", "description": "安装验证时 java -version 的输出" },
          "imported": { "type": "boolean", "default": false },
          "installedAt": { "type": "string", "format": "date-time" }
        }
      }
    }
  }
}
```

`.jdmrc`（项目根）与 `~/.jdm/default` 同格式：单行 `<vendor>@<version>`。
